# Third-party data in kedfix

kedfix's code is MIT (see LICENSE). It ships tables and word lists built from the sources below.
`scripts/build-data.ts` rebuilds every generated file in `src/generated/` from `data/`.

## Keyboard layouts

| Layout | Source |
|---|---|
| `kedmanee` (Windows / TIS 820-2538) | Unicode CLDR release-40, `keyboards/windows/th-t-k0-windows.xml` (generated by CLDR from Windows 10). The two keys where Windows and macOS differ (`` ` `` and `3`) were checked against kbdlayout.info's KBDTH0 page. |
| `kedmanee-mac` | Unicode CLDR release-40, `keyboards/osx/th-t-k0-osx.xml` — checked key for key against what macOS 27 itself types (`com.apple.keylayout.Thai`, read with `UCKeyTranslate` by `scripts/layouts/macos-dump.swift`); identical. `build-data.ts` fails if they ever differ. |
| `pattachote` (Windows) | Unicode CLDR release-40, `keyboards/windows/th-t-k0-windows-patta.xml`. The backslash key types a private-use character (U+F8C7) there and is left out. |
| `pattachote-mac` | What macOS 27 types (`com.apple.keylayout.Thai-PattaChote`, same dump). CLDR's 2014 file differs on one key (`}`: CLDR ภ, macOS 27 ฦ); the OS wins. |

Raw files: `data/sources/cldr/*.xml`, `data/sources/macos/macos-27-thai-layouts.tsv`.

## Thai word list

`data/sources/icu-thaidict.txt` — ICU 76.1 `icu4c/source/data/brkitr/dictionaries/thaidict.txt`
(26,383 words). Header: "Copyright (C) 2016 and later: Unicode, Inc. and others. License & terms of
use: http://www.unicode.org/copyright.html — Copyright (c) 2006-2015 International Business Machines
Corporation, Apple Inc., and others. All Rights Reserved." Licensed under the Unicode License v3
(text below). kedfix ships the 13,847 words that are not two or more other words joined, front-coded.

## English word list

`data/sources/12dicts-3esl.txt` — the "3esl" list of Alan Beale's 12dicts, from Kevin Atkinson's
Alt12Dicts package (wordlist.aspell.net, mirrored at github.com/en-wl/wordlist, branch v1,
`alt12dicts/3esl.txt`). Its README: "All of these files have been explicitly placed in the Public
Domain by Alan Beale." Alan Beale asks that 12dicts be acknowledged — thank you.
`data/extra-english.txt`, `data/common-thai.txt` and `data/names.txt` were written for kedfix (MIT).
